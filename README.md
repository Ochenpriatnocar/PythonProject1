# Мой банк

## 1. Данный проект является разработкой виджета финансовых операций в банковском приложении.

## 2. Имеющиеся модули содержат функции:
 - маскировки номера карты
 - маскировки счета карты
 - маскировки значений номера или счета карты
 - фильтрации операций по статусу, а также по дате
 - Декоратор возвращающий или записывающий результат работы функций лог файл
 - фильтрации операций по валюте платежа
 - отображения информации о платежах
 - генерации номеров карт
 - обработка данных из .json файлов
 - отправки Api запросов и получения данных с удаленных серверов
 - логирования других функций


## 3. Имеющиеся модули проверяющие правильность работы основных модулей:
 - тестирование модуля маскировки номера карты
 - тестирование модуля маскировки счета карты
 - тестирование модуля маскировки значений номера или счета карты
 - тестирование модуля фильтрации операций по статусу, дате, а также 
 - тетирование работы модуля при не корректном вводе даты
 - тестирование декоратора функций
 - тестирование работы модуля при не корректном вводе даты
 - тестирование работы модуля отвечающего за фильтрацию платежей по валюте платежа, 
 - отображения информации о платеже, а также генерации номеров карт
 - корректности обработки данных при чтении из .json
 - корректности получения запросов Api

## 5. Использование

1. Для маскировки счета карты используйте функцию: mask_account_card()
2. Для маскировки номера карты используйте функцию: get_mask_card_number()
3. Для маскировки значения или нома или счета карты используйте функцию: mask_account_card()
4. Для приведения формата даты в читаемый формат используйте функцию: get_date()
